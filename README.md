# ToDoMaster (TDM)

> macOS 原生待办事项管理与便笺工具 · 为高效备考与日常任务管理而生

![Platform](https://img.shields.io/badge/platform-macOS%2013%2B-blue) ![Swift](https://img.shields.io/badge/Swift-5.9-orange) ![License](https://img.shields.io/badge/license-MIT-green)

---

## 简介

ToDoMaster（简称 **TDM**）是一款 macOS 原生待办事项应用，采用 Swift + AppKit 构建。它不仅是一个任务列表，更是一个**智能任务解析器**和**桌面便笺系统**——将通知文本一键解析为结构化任务，将选中任务投射到桌面便笺上随时可见。

专为需要多线程管理学习/工作任务的用户设计。

---

## 功能特性

### 📋 任务管理

| 功能 | 说明 |
|------|------|
| **智能解析** | 粘贴通知/消息文本，自动提取任务名称、时间、地点、备注，支持时间段（如 `8:30-10:00`）和相对日期（如"下周五"） |
| **手动创建** | 通过表单添加完整任务信息（任务名、日期时间、结束时间、地点、备注、星标） |
| **星标置顶** | 重要任务一键星标，紫色高亮并自动置顶 |
| **紧迫性配色** | 根据剩余天数自动标注背景色：🔴 红（≤3天）· 🟡 黄（≤7天）· 🔵 蓝（≤15天）· 🟢 绿（≤30天）· 🟣 紫（今天） |
| **倒数日** | 实时显示距离任务的天数，支持切换精确到小时/分钟 |
| **过期标记** | 已过期任务自动划横线 |
| **多选导出** | Cmd+点击多选任务，一键导出为 Markdown 文件 |
| **右键编辑** | 右键点击任意列直接编辑对应字段 |
| **双击编辑** | 双击单元格进入编辑模式 |
| **数据持久化** | 自动保存至本地 JSON，重启不丢失 |

### 📝 便笺系统

| 功能 | 说明 |
|------|------|
| **一键生成** | 选中任务点击"便笺"按钮，在桌面生成置顶便笺 |
| **智能排序** | 按紧迫度颜色排序（紫→红→黄→蓝→绿→灰） |
| **去重** | 已在便笺中的任务不会重复添加 |
| **倒数日显示** | 便笺中每个任务显示倒数信息 |
| **自由拖动** | 便笺可拖拽到任意位置 |
| **可调大小** | 拖拽边角调整便笺尺寸 |
| **双透明度** | 便笺背景透明度（0%~100%）和字体透明度（20%~100%）独立调节 |
| **自定义颜色** | 调色板自由选择便笺背景色，文字自动适配深/浅色 |
| **边框开关** | 可选择显示/隐藏便笺边框 |
| **折叠模式** | 鼠标移开 N 秒后自动折叠为一行标题栏，悬停展开 |
| **折叠透明度** | 折叠状态下独立透明度控制 |

### 🌙 深夜模式

全局暗色主题，一键切换应用和便笺的外观。深夜学习时保护眼睛。

### 🖥️ 状态栏集成

- **状态栏图标** ☑ 常驻菜单栏
- **左键点击**：显示/隐藏便笺（显示时定位到图标正下方）
- **右键菜单**：显示 TDM · 新增任务 · 便笺设置 · 删除便笺

### ⚡ 效率设计

- **后台运行**：点击红叉隐藏窗口，应用继续在后台运行；Dock 右键退出才真正关闭
- **全局快捷键**：`Cmd + Shift + D` 快速启动
- **Spotlight 集成**：`Cmd + Space` 输入 "TDM" 即可搜索启动
- **虚线分隔**：表项之间虚线分隔，视觉清晰
- **日期显示**：窗口右上角实时显示当前日期和星期

## 构建与运行

```bash
# 克隆仓库
git clone https://github.com/your-username/ToDoMaster.git
cd ToDoMaster

# 编译
swift build

# 复制到应用包并启动
cp .build/debug/TodoApp ToDoMaster.app/Contents/MacOS/TodoApp
open ToDoMaster.app
```

### 安装为应用

将 `ToDoMaster.app` 拖入 `/Applications` 文件夹即可。

### 配置 Spotlight 关键词（可选）

```bash
defaults write com.vira.todoapp CFBundleKeywords -array "TDM" "ToDoMaster" "Todo" "待办"
```

### 配置全局启动快捷键（可选）

创建 Automator Quick Action 并绑定 `Cmd + Shift + D`：

```bash
# 1. 打开 Automator → 新建 → 快速操作
# 2. 添加"运行 Shell 脚本"，内容：
open /Applications/ToDoMaster.app
# 3. 保存为 "Launch ToDoMaster"
# 4. 系统设置 → 键盘 → 键盘快捷键 → 服务 → 绑定 Cmd+Shift+D
```

## 使用指南

### 智能解析

在输入框中粘贴任意包含任务信息的文本，点击解析按钮：

```
输入：8:30考试，地点在数字化大楼317机房
解析：任务=考试  时间=8:30  地点=数字化大楼317机房

输入：下周五下午2点开组会，三教405
解析：任务=开组会  时间=下周五 14:00  地点=三教405
```

### 便笺操作

1. 在表格中 **Cmd+点击** 选中多个任务
2. 点击 **"便笺"** 按钮
3. 便笺出现在状态栏图标正下方
4. 左键状态栏图标 ☑ 切换显示/隐藏
5. 右键图标打开设置菜单

### 便笺设置

| 设置项 | 范围 | 说明 |
|--------|------|------|
| 便笺透明度 | 0%~100% | 便笺背景整体透明度 |
| 字体透明度 | 20%~100% | 文字内容透明度 |
| 显示边框 | 开/关 | 便笺边框显隐 |
| 鼠标移开时折叠 | 开/关 | 移开后自动折叠为标题栏 |
| 折叠延时 | 1~30秒 | 自定义折叠等待时间 |
| 折叠透明度 | 10%~100% | 折叠状态下的独立透明度 |
| 深夜模式 | 开/关 | 全局暗色主题 |
| 便笺颜色 | 自由选择 | 便笺背景色，文字自动适配 |
