# ToDoMaster (TDM)

> macOS 原生待办事项管理与桌面便笺工具 · 为高效备考与日常任务管理而生

## 简介

ToDoMaster（简称 **TDM**）是一款 macOS 原生待办事项应用，采用 Swift + AppKit 构建。它不仅是一个任务列表，更是一个**智能任务解析器**、**今日/长期分区管理系统**和**桌面双便笺系统**——将通知文本一键解析为结构化任务，将选中任务投射到桌面便笺上随时可见、随时勾选。

专为需要多线程管理学习/工作任务的用户设计。

## 功能特性

### 📋 任务管理

| 功能 | 说明 |
|------|------|
| **智能解析** | 粘贴文本自动提取任务名称、时间、地点、备注，支持时间段（`8:30-10:00`）、相对日期（"下周五"）、日期（"10月21日"） |
| **手动创建** | 完整表单添加任务，支持勾选"📅 加入今日待办"直接入今日 |
| **今日/长期分区** | 双分区表格，今日任务自动归类，表头可折叠/展开 |
| **随机任务** | 🎲 Roll Something To Do——随机生成轻松小任务（时间自动为 15 分钟整数倍） |
| **星标置顶** | 一键星标，紫色高亮加粗并自动置顶 |
| **紧迫性配色** | 按剩余天数自动标注背景色：🔴≤3天 · 🟡≤7天 · 🔵≤15天 · 🟢≤30天 · 🟣今天 |
| **智能倒数** | 当天任务自动显示小时/分钟倒数（如"3时30分"），未来任务显示天数 |
| **过期管理** | 灰色文字 + 划横线 + 浅灰背景（自适应主题），置底显示方便清理 |
| **多选操作** | Cmd+点击多选，支持批量导出 Markdown、批量删除 |
| **右键/双击编辑** | 右键编辑单列字段，双击单元格编辑 |
| **手动刷新** | ⟳ 一键同步表格和便笺数据 |
| **数据持久化** | 本地 JSON 存储，重启不丢失 |

### 📝 双便笺系统

| 功能 | 说明 |
|------|------|
| **今日便笺** | 点击今日表头"📅 今日便笺"自动生成，无需选中 |
| **长期便笺** | 选中任务后点击长期表头"📝 长期便笺"生成 |
| **智能叠放** | 两便笺上下排列不遮挡，折叠显示标题 |
| **便笺勾选** | 便笺内直接点击勾选框标记完成，**双向实时同步** |
| **标题常驻** | 展开/折叠均显示便笺名称（Today / Memo） |
| **❌ 关闭 / 📌 锁定** | 关闭不删除数据；锁定后不可移动/调整大小 |
| **三透明度** | 便笺（0~100%）· 字体（20~100%）· 折叠（10~100%）独立调节 |
| **八色调色板** | 🎨 弹出式 3×3 色块选择 + 自定义调色盘 |
| **自动折叠** | 鼠标移开 N 秒自动折叠（延时可调 1~30 秒） |
| **贴边定位** | 便笺位置可选：图标正下方 / 四角 / 顶部居中 |
| **桌面隔离** | 便笺默认仅留在创建桌面，可选跟随切换 |
| **拖拽约束** | 屏幕边界约束，不会飞出屏幕或被系统吸附放大 |

### 🌙 深夜模式

全局暗色主题一键切换，过期项背景自适应。便笺颜色支持**跟随主题变色**（浅色系↔深色系自动切换）。

### 🖥️ 状态栏集成

- **☑ 图标** 常驻菜单栏
- **左键**：显示/隐藏所有便笺（定位到图标正下方）
- **右键菜单**：显示 TDM · 新增任务 · 便笺设置 · 删除便笺（多便笺可选删除）

### ⚡ 效率设计

- **后台运行**：红叉隐藏窗口，Dock 右键退出
- **全局快捷键**：`Cmd + Shift + D` 启动
- **Spotlight**：`Cmd + Space` 输入 "TDM"
- **使用说明**：设置内置完整使用指南

## 构建与运行

```bash
git clone https://github.com/Vincent-Bray/ToDoMaster.git
cd ToDoMaster
swift build
cp .build/debug/TodoApp ToDoMaster.app/Contents/MacOS/TodoApp
open ToDoMaster.app
```

### 安装

将 `ToDoMaster.app` 拖入 `/Applications` 即可。

### 可选配置

```bash
# Spotlight 关键词
defaults write com.vira.todoapp CFBundleKeywords -array "TDM" "ToDoMaster" "Todo" "待办"

# 全局快捷键 Cmd+Shift+D
# Automator → 快速操作 → Shell 脚本: open /Applications/ToDoMaster.app
# 系统设置 → 键盘 → 键盘快捷键 → 服务 → 绑定
```

## 使用指南

### 智能解析

```
输入：8:30-10:00考试，地点在数字化大楼317机房
解析：任务=考试  时间=8:30-10:00  地点=数字化大楼317机房

输入：下周五下午2点开组会，三教405
解析：任务=开组会  时间=下周五 14:00  地点=三教405
```

### 便笺操作

1. **今日便笺**：点今日表头"📅 今日便笺"——自动读取所有今日任务
2. **长期便笺**：Cmd+选中任务 → 点长期表头"📝 长期便笺"
3. 便笺自动折叠/展开，勾选框直接标记完成（双向同步）
4. ❌ 关闭 · 📌 锁定 · 🎨 换色 · 拖拽移动

### 便笺设置（右键状态栏 ☑ → 便笺设置）

| 设置 | 范围 | 说明 |
|------|------|------|
| 便笺透明度 | 0~100% | 便笺背景透明度 |
| 字体透明度 | 20~100% | 文字内容透明度 |
| 折叠透明度 | 10~100% | 折叠态独立透明度 |
| 显示边框 | 开/关 | 便笺边框显隐 |
| 鼠标移开折叠 | 开/关 | 移开后自动折叠 |
| 折叠延时 | 1~30秒 | 可直接输入数字 |
| 深夜模式 | 开/关 | 全局暗色主题 |
| 便笺颜色 | 8 色 + 自定义 | 🎨 弹出选色，📝 打开调色盘 |
| 跟随主题变色 | 开/关 | 颜色随日/夜模式切换 |
| 跟随桌面切换 | 开/关 | 便笺是否出现在所有桌面 |
| 便笺位置 | 6 选项 | 图标下方/四角/居中 |
